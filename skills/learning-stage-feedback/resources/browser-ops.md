# 浏览器操作细节与坑（Playwright MCP 实测）

本文件记录在 follow-class-reminder 站点上实际验证过的浏览器操作要点，供执行时对照。

## 1. 文件上传（导入 Excel）

- 页面上的 file input（Choose File）是 sr-only 隐藏元素，直接点击会因被遮挡而超时。**点可见的「点击选择或拖入 Excel」按钮**触发文件选择器。
- 点击后进入文件选择器 modal 状态：此时除 browser_file_upload 外，其它浏览器工具会报 “does not handle the modal state”。先完成上传再继续。
- browser_file_upload 只接受 Playwright MCP 允许根目录内的路径（报错信息会列出 allowed roots）。Excel 在桌面/其它盘时，**先用 shell 复制到允许根目录**，再以上传。
- 上传成功后等待快照出现：「已识别工作表“学情阶段反馈”，表头位于第 N 行」+「N 名学生 / M 条记录 / K 个课次」。
- 同浏览器会话内导入状态会保留（页面说“Excel 仅在当前浏览器处理”）；浏览器上下文重置后需重新导入。

## 2. 点击与输入

- 若浏览器工具调用要求 target 参数（如 browser_click 报缺少 target），把 ref 的值同时传给 target。
- 输入用 browser_type 的 fill 语义（覆盖原文）。填完 SQL 后等待 1~2 秒让校验生效。
- 下拉选择：模板选择器、科目、讲次等是 role=option 列表；先点按钮展开，再点 option。

## 3. SQL 校验等待

- 校验结果文本形如「校验通过 · 返回 状态」或「SQL语法有误，请检查字段名、逗号、括号和别名。」。
- 「保存查询」按钮 disabled = 校验失败；必须等 enabled 再点保存。
- 校验通过 ≠ 逻辑正确：CASE WHEN 版本条件不满足会返回 1 行 NULL（残句），需要 0 行隐藏时必须用 GROUP BY + HAVING。

## 4. 模板管理弹窗

- 两个入口：导入页顶部「管理共享模板」、工作台反馈区「管理模板」，打开的是同一个「共享模板管理」弹窗。
- 弹窗左侧内置模板条目（完课反馈/综合模板/阶段详评/进度激励）带删除按钮；自定义模板是可点击条目，未保存的标「未保存」。
- 保存到服务器后提示「共享模板已保存，其他老师同步后即可使用」；他人点「同步」拉取。
- 「同步」点击后提示「已同步服务器上的最新模板」。
- 全局平均值的空值规则有 4 组（忽略该行/按指定值计入）。

## 5. 工作台要素

- 学生列表编号按 Excel 顺序；搜索框支持姓名或 ID；已复制的学生带 ✓ 与计数。
- 学生头部「STUDENT n / 179」+ 记录条数；上一位/下一位按钮。
- 表格图片尺寸随记录数变化（如 1630×254px / 1630×422px），复制为高清原图。
- 复制区：复制姓名/复制表格图片/复制评语/下个学生；完课反馈是复制上半截/下半截。
- 「下个学生」跳到名单下一位且沿用当前模板。
- 换种说法按钮在部分模式下可用（disabled 时无效）。
- 阶段详评有发送对象切换（给家长/给学生）；完课反馈有科目下拉（只列该学生有数据的科目）；进度激励有「进展到第 N 天」输入。

## 6. 反馈范围（重要）

- 阶段反馈范围 = 第1讲至当前学生最高讲次，不同学生范围不同（标题会变，如第1—2讲 / 第1—3讲）。
- 「补01」等补课讲次被范围排除——测试选学生前先按范围核对数据（openpyxl 只统计范围内讲次）。

## 7. 环境相关

- 线上版与本地开发版功能一致；本地未部署时 localhost:3010 连接会被拒绝。
- 线上模板全员共享、无个人隔离；删除/保存会影响所有老师，操作前确认。
- 浏览器工具进程崩溃/网络中断时：重新 navigate 并重新导入 Excel 即可。
## 8. 站点 UI 世代识别（先快照再动手）

站点历史上出现过两代 UI，且新旧版按钮完全不同。进入页面后先 snapshot 判断：

- **新版（2026-08 重部署后）**：导入页顶部有「管理共享模板」按钮；工作台反馈区是「反馈模板」下拉选择器 + 「管理模板」按钮；管理弹窗有 新增/同步/搜索/复制为新模板/保存到服务器。
- **旧版（更早部署）**：工作台反馈区是 5 个平铺按钮（综合模板/阶段详评/完课反馈/进度激励/简短说法）+ 「设为默认/当前默认」+「换种说法」；进度激励带「进展到第 N 天」输入；没有自定义模板管理。
- 旧版下配置自定义模板不可行（没有管理入口）；只做只读核对或提醒用户部署新版。

## 9. 临时决策速查（其它机器常见异常）

| 现象 | 决策 |
|---|---|
| 浏览器工具缺失 | 让用户跑 install.ps1/verify.ps1，新开会话；先交付确认稿 |
| localhost 连接拒绝 | 改用线上 pages.dev |
| 页面无导入按钮 | 快照核对是否加载中/被拦截；刷新重试 |
| 上传路径被拒 | 按报错列出的 allowed roots 复制文件后再传 |
| Excel 被占用 | 用 FileShare.ReadWrite 打开复制 |
| 「校验通过」不出现 | 读错误文本改 SQL；试 CASE WHEN / GROUP BY+HAVING 变体 |
| ref 找不到 | 重新 snapshot 取新 ref |
| modal 卡住 | browser_file_upload 收尾，或关闭/Escape |
| 表格图片尺寸异常 | 正常：尺寸随记录数变化 |
| 学生搜索无结果 | 换 ID 搜索；确认已导入 |
| 中文脚本乱码 | 重写为纯 ASCII 输出（Windows PowerShell 5.1 编码坑） |
