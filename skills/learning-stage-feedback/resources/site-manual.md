## 二、学情阶段反馈：导入页

1. 顶部：「管理共享模板」按钮 + 提示「Excel 仅在当前浏览器处理」。
2. 01 导入学情 Excel：
   - 自动寻找名为「学情阶段反馈」的工作表；多级表头（本数据表头在第 3 行）。
   - 支持 .xlsx/.xls；原始文件不上传，仅浏览器本地处理。
   - 移除按钮可清除已导入文件。
   - 识别后显示：N 名学生 / M 条记录 / K 个课次。
3. 02 选择反馈方式：
   - **阶段反馈**：按每位学生当前进度自适应（第1—N讲，N=该学生最高讲次；不同学生范围不同）。
   - **单讲反馈**：固定某一讲（下拉选第 1/2/3 讲），默认使用短评语。
   - 进入反馈工作台按钮。
4. 底部说明卡：出勤判断（出勤时长+回放时长）÷完课时长，85%以上良好、60%以下需补课；练习判断总分“－”的课程自动排除。

## 三、反馈工作台

- 左侧 01 学生名单：按 Excel 顺序编号；搜索框支持姓名或 ID；「N/179 已复制」计数；已复制的学生带 ✓ 图标。
- 右侧学生头部：STUDENT n / 179、姓名标题、记录条数、学生ID；「上一位 / 下一位」按钮。
- 02 统计卡（随学生变化）：平均出勤率（附建议）、出门测完成 x/y（附说明）、已交平均正确率（附建议）。
- 03 反馈表格图片：按 Excel 选中单元格样式生成，显示像素尺寸（如 1630×422px），复制用原始高清尺寸。
- 04 反馈评语区：
  - **反馈模板选择器**：内置 4 个（完课反馈/综合模板/阶段详评/进度激励）+ 自定义模板；搜索框过滤。
  - **管理模板**按钮：打开共享模板管理弹窗。
  - 各模板的附加控件：
    - 完课反馈：科目下拉（只展示该学生有数据的科目）。
    - 阶段详评：发送对象切换（给家长/给学生，语气随对象变化）。
    - 进度激励：「进展到第 N 天」数字输入（只保存在当前浏览器，不影响其他用户）。
  - **换种说法**按钮：部分模式下可用，同模式下重新生成另一种措辞。
  - 评语 textbox 可手动编辑（提示“可直接修改称呼或措辞”），显示字数。
  - 系统判断依据区：展示该模板的生成逻辑（如综合分公式、科目分级原因）。
- 05 复制区：复制姓名 / 复制表格图片 / 复制评语 / 下个学生。
  - 「下个学生」跳到名单下一位，**沿用当前模板**。
  - 完课反馈特殊：分「复制上半截 / 复制下半截」两次复制。
  - 提示：需要可编辑评语时，先复制表格图片粘贴，再复制评语。

## 四、共享模板管理弹窗

- 左侧：新增 / 同步 / 搜索反馈模板；内置模板列表（可删除）；自定义模板列表（未保存标「未保存」）。
- 右侧编辑区：
  - 模板名称输入框。
  - 复制为新模板 / 删除 / **保存到服务器**（保存后提示“共享模板已保存，其他老师同步后即可使用”；其他老师点「同步」拉取最新）。
  - **全局平均值的空值规则**（4 组：忽略该行 / 按指定值计入）。
  - 话术内容：**固定句** / **条件句组**两种内容块。
  - 每个内容块：编号、类型标签、「与上一块连接」（空一行/直接换行/紧接上一句）、折叠/删除；话术 textbox；「新增查询」。
- SQL 查询弹窗：查询名称 + SQL 输入框 + 实时校验（“校验通过 · 返回 N 项字段名”或“SQL语法有误”）+ 多行格式（每项换行/顿号连接/分号连接/自定义）+ 自动编号勾选 + 取消/保存查询。
- 保存的查询在块内显示：查询名 + 返回字段数 + 编辑/删除查询按钮。

## 五、数据模型（关键认知）

1. **全局数据 = 当前选中学生 + 当前反馈范围的全部有效行**，不是整份 Excel。切换学生后同一条 SQL 自动查询下一名学生。
2. 因此聚合统计天然就是“当前学生这一组”——**无需 GROUP BY 学生ID**（实操中块4保留它只因校验器不接受无 GROUP BY 的 HAVING）。
3. Excel 的「-」= SQL NULL，用 IS NULL / IS NOT NULL 判断。
4. 百分比 0~100 数字（80% 写 80）。
5. 出勤率 = 完课时长÷120×100；课堂参与率 = 答题数÷总题数×100。
6. 课次名称去掉讲次编号和分类标签；「补01」等补课讲次被反馈范围排除。
7. 反馈范围自适应：阶段反馈范围=第1讲至该学生最高讲次；单讲反馈=指定讲次。

### SQL 可用字段（Excel 原始中文名）
基础：学生ID、学生姓名、课次讲数、课次名称、科目、专属辅师
出勤：出勤时长（分钟）、回放观看时长（分钟）、完课时长（分钟）、出勤率
课堂：答题数、答题正确数、总题数、正确率、课堂参与率
课后：出门测得分、出门测总分、出门测正确率

## 六、SQL 硬性规则（Word 第七部分 + 实测修正）

- 只允许**一条 SELECT**，FROM 全局数据；末尾无分号；无 -- 或 /* */ 注释。
- 字段名用 Excel 原始中文名；关键字大小写不敏感；AND/&&、OR/|| 等价。
- 支持：AVG/MAX/MIN/SUM/COUNT/ROUND/COALESCE/IFNULL、CASE WHEN、GROUP BY/HAVING、ORDER BY、LIMIT。
- 聚合后筛选必须用 HAVING（不能用 WHERE 写聚合）。
- **实测修正 1**：不带 GROUP BY 的 HAVING 校验报「SQL语法有误」。
- **实测修正 2**：CASE WHEN …THEN '文案' END 条件不满足返回 1 行 NULL（不隐藏整行、会出残句）；要“0 行隐藏”必须 GROUP BY + HAVING。
- 话术引用：查询名.字段名（全部）、.字段名1（第1条）、.字段名1~3（第1~3条）；同一行多字段用 { } 循环；查询 0 行→整行隐藏。
- **ykt 占位符必须写 ykt（不带花括号）**；写 {ykt} 会残留大括号。
- 自动编号默认勾选，不需要编号时必须取消。

## 七、内置模板速览

| 模板 | 逻辑 | 附加控件 |
|---|---|---|
| 完课反馈 | 按科目列出出门测错题知识点（正确率从低到高，最多 7 个）；全未提交显示“异常” | 科目下拉 |

| 进度激励 | 固定 5 块话术：称呼+进展天数、课程状态、出门测状态、脱颖而出鼓励（全完成才显示）、结尾鼓励 | 进展到第 N 天 |

## 八、如需在网页上人工微调（可选）

AI 通过 API 创建/修改后，老师也可以直接在网页上小改；但注意网页端保存会以网页当前配置覆盖线上同 id 模板，改前最好让 AI 先 GET 备份。

1. 导入 Excel → 选阶段反馈 → 进入反馈工作台。
2. 反馈模板选择器 → 管理模板（或导入页顶部「管理共享模板」）。
3. 左侧选中 AI 刚创建的模板 → 直接编辑名称、话术、查询。
4. 「保存到服务器」→ 关闭 → 模板选择器选中 → 逐学生验证。
5. 改完告诉 AI「我在网页上手动改过了」，AI 再改前会重新读取最新版本。

## 九、测试方法（三类学生）

1. 用 Python openpyxl 读 Excel，按学生聚合算课程/出门测状态。
2. 选三类代表：全完成 / 某天<100 或空 / 边界（99.98）。
3. 页面搜索学生 → 核对评语：课程行、出门测行、条件行（全完成才显示）、结尾固定句。
4. 验证「下个学生」沿用模板、复制评语、复制表格图片。

## 十、踩坑清单

1. ykt 占位符不带花括号。
2. 自动编号要取消。
3. 校验通过 ≠ 逻辑正确（CASE WHEN NULL 行）。
4. 反馈范围排除补课/超范围讲次——测试选学生前先按范围核对数据。
5. 线上保存的模板所有老师共享（无个人隔离）；AI 通过 API 写入同样全员可见。
6. 网页端「同步」拉取的是线上最新模板；AI 写入后如果网页没变化，先点「同步」或刷新。
7. API 写入后最终效果仍以网站渲染为准，发现不对就带原句告诉 AI 修改。
